How to use it

  1. Go over the list together on the first day of summer break.
  2. Agree on the rule: a full row for today means screen time is on.
  3. Post it where kids can see it first thing in the morning.
  4. Change the house chore each week so nobody gets stuck with the same one.
  5. Print a fresh copy every Monday. Kids like starting over.
